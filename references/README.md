# Reference preservation policy

This repository catalogues the referenced scholarly literature and textbooks, including persistent DOI links. A DOI link is **not** a stored article PDF.

Before adding any full text, check the publisher's license, author-accepted-manuscript permissions, or open-access license. Record the source URL, license, version, access date and attribution. Do not upload paywalled publisher PDFs without redistribution permission. A public repository does not itself provide a right to redistribute copyrighted papers.

Current status: citation catalogue populated; no full-text PDFs archived yet. Bibliographic metadata and DOI targets require source-by-source verification before being labelled fully verified.
